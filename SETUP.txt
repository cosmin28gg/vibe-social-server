WEBSOCKET SERVER SETUP
======================

WHY: Supabase broadcasts are shit. This gives you WhatsApp-style instant messaging.

SETUP:
1. cd server && npm install
2. Copy .env.example to .env
3. Add your SUPABASE_URL and SUPABASE_SERVICE_KEY
4. npm start

DEPLOY:
- Railway.app (easiest, free tier)
- DigitalOcean ($5/month)
- Any VPS with Node.js

FLUTTER:
- WebSocketService.instance.connect() on app start
- Use WebSocketService.instance.sendMessage() instead of supabase.from('messages').insert()
- Messages save to local SQLite FIRST (instant), then sync to Supabase in background

RESULT:
- Messages appear instantly (5-10ms)
- No more flickering
- No more polling
- Works offline
- Guaranteed delivery
